# Expression Package Creation — 表情包制作 Skill

这是一套可复用的零基础表情包制作工作流，不绑定任何特定角色或平台。入口文件为 `SKILL.md`，其余为按需读取的参考资料和可复制模板。

## 使用方法

1. 在支持导入/安装 Skill 的环境中导入整个文件夹或解压 ZIP 后使用；具体导入方式取决于平台。
2. 调用示例：`使用 expression package creation，帮我策划16张原创柴犬动态表情包，适合工作群。`
3. 若已有角色，附上参考图片并说：`以这张角色为唯一参考，做8张表情，先出脚本和静态初稿审核。`
4. 若只需要零基础教程，调用：`用这个Skill生成8张3:4的表情包制作教学图。`

## 文件导航
- `SKILL.md`：总规则与完整流程
- `references/prompts.md`：可复制AI提示词
- `references/expression-catalog.md`：高频表情动作与文字库
- `references/animation-and-export.md`：动效和GIF制作
- `references/qa-and-submission.md`：技术审核、版权与投稿
- `templates/project-brief.md`：项目立项
- `templates/sticker-plan.csv`：表情分镜计划表
- `templates/qa-checklist.md`：逐张质检清单

## 原则
- “静态策划/草稿”不等于“动态GIF成品”。
- 角色与文字错误先修好，再做动效。
- 目标平台规范可能更新，不能仅凭旧尺寸示例认定已合规。
- 未经真实平台反馈，不宣称已通过审核。
